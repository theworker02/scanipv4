# scanipv4

Scan HTML/Markdown ipv4 fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/scanipv4/

## Install / run

```bash
git clone https://github.com/theworker02/scanipv4.git
cd scanipv4
node src/cli.js
node --test
```
